Polysnap

A bilateral coordination test. Each hand traces its own shape, one point per beat.

  1. Stand back so both hands are in frame, index fingers up.
  2. On every beat, snap each fingertip into the lit point's circle. How you get there doesn't matter.
  3. Both hands start on point 1: left hand at the top, right hand at the bottom. Each shape loops at its own length.
  4. Miss one beat with either hand and the round is over.
